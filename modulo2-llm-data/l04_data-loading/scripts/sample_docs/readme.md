# MeteoCLI

**MeteoCLI** è uno strumento da riga di comando per consultare le previsioni del
tempo senza aprire il browser. Open source, scritto in Python.

## Installazione

    pip install meteocli

## Uso

    meteo oggi Milano
    meteo settimana Roma --gradi celsius

## Funzionalità

- Previsioni a 7 giorni per qualsiasi città
- Output a colori nel terminale
- Cache locale per ridurre le chiamate all'API
- Esportazione in JSON
